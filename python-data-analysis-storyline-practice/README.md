# Python Data Analysis Practice Project

Interactive Storyline 360 practice project covering:

- Python Fundamentals
- Control Structures, Loops and Functions
- NumPy
- Matplotlib
- Pandas

The project contains 250 mixed-format practice questions with section results, feedback, review, retry, and retake navigation.

## Outputs

- Storyline source file
- SCORM package for LMS deployment
- Web-published interactive version
- Question-bank source files
